# Model checkpoints

Place the compatible Attention U-Net checkpoint at `models/au_net_crack.pth`, or pass another path with `--model`. Checkpoints are excluded from Git until their training data provenance and distribution license are verified.

The distributable synthetic demo parameters are tracked separately at `src/borehole_fracture_analysis/resources/demo_linear_segmenter.json` and run with `borehole-fracture demo`.
